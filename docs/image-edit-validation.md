# 그림 선택·삭제·크기 조절 검증 (2026-10-24)

## 수정 전 재현

일반 자막 편집의 `editShape`가 기존 템플릿 그림을 목록에서 제외하고, 삭제도 추가한 요소에만 허용했다. 미리보기에는 이동만 있고 크기 조절 손잡이가 없었다. Make 마스터의 직접 편집 좌표는 `manualGeometry`로 표시되지 않아 화면을 거의 채우는 그림이 배경으로 재판정될 수 있었다.

## 변경

- 일반 편집에서도 기존 그림을 요소 목록과 클릭 대상으로 제공하고 선택 그림 삭제를 허용한다. 본문 글상자 삭제는 계속 막는다.
- 공통 편집 미리보기에 8방향 크기 조절 손잡이를 추가한다. 모서리에서 Shift를 누르면 비율을 유지하며, 기존 위치·너비·높이 입력과 같은 좌표를 사용한다.
- 일반 장의 그림 변경·삭제는 본문 재생성 때 해당 장에 보존한다. 공유 템플릿을 덮어쓰지 않으며, 그림 편집 여부를 PPTX 부가 정보에도 보관한다. 마스터에서 추가한 그림을 일반 장에서 삭제한 경우에도 다시 나타나지 않는다.
- Make 마스터의 숫자·끌기·방향키 변경을 수동 좌표로 보존한다. Make 덱의 마스터 수정도 새 장 생성 및 방송용 전환에 전달한다.
- 그림 교체는 새 이미지 원본 크기·비율과 무관하게 기존 x/y/w/h를 유지한다. 파일 추가와 배경 교체의 기존 동작은 유지한다.
- 변경된 공통 파일의 로딩 버전을 양쪽 화면에서 갱신한다.

## 통과

Windows Chrome / Playwright, 별도 테스트 브라우저 저장소에서 확인:

- `inherited_image_edit_browser.cjs`: 수정 전 기존 그림 선택 실패 재현. 수정 후 PPT·Make 일반 편집에서 기존 그림 선택, 손잡이·숫자 크기 조절, 다른 종횡비 이미지 교체 시 화면 크기·위치 보존, 삭제, 본문 편집 후 보존, 다른 장·레이아웃 불변성, 마스터 적용·삭제, PPTX 왕복. Make 템플릿 마스터의 수치·손잡이 조절, 미리보기, 저장·재열기·삭제.
- `master_media_browser.cjs`: 그림 추가·붙여넣기·교체·복제·삭제·순서·배경·글상자·도형, 같은 레이아웃 적용과 다른 레이아웃 보호, 새 장, 원고 연결 및 PPTX 왕복.
- `image_library_browser.cjs`: 두 편집 화면의 보관함·미리보기·저장·재열기·PPTX 왕복, 기존 템플릿 및 원고 연결 보존.
- `builtin_assets_browser.cjs`: 기존 및 신규 그림·배경 17개 선택·저장·투명도·PPTX 왕복.
- `template_isolation_browser.cjs`: 템플릿 전환·저장 시 마스터 격리.
- `editor_media.cjs`, `layout_masters.cjs`, `make_transfer.cjs`: 그림 보존·삭제 및 중복 방지, 레이아웃 상속, 전환·백업·원자적 저장 실패 보호.
- 변경 JavaScript 문법 검사와 `git diff --check`.

기존 템플릿 이미지 파일과 기본 디자인은 교체하지 않았다. 실제 마이크·물리 외부 모니터 송출·클라우드 동기화는 이번 그림 편집 변경에서 별도로 시험하지 않았다. 배포 후 동일 브라우저 재현 검사를 별도 수행한다.
