# 파스텔 장식 배너 6종 기본 그림 등록 (2026-10-24)

## 변경

- 이번 대화에서 최종 제작한 투명 PNG 6종을 `ppt/images/library/v2/`에 새 파일로 추가했다.
- 초록 잎사귀·파랑 물결·분홍 꽃·보라 잎사귀·골드 리본은 약 7.38:1, 파랑 기하학은 추가 높이 요청을 반영한 약 6.3:1이다. 바깥 여백은 최소화했고 글쓰기 영역은 불투명하다.
- 공통 카탈로그 버전을 3으로 올리고 새 ID로 등록했다. PPT 만들기 마스터와 방송용 PPT 편집의 ‘그림 가져오기’에서 선택할 수 있다.
- 기존 11개 항목, 기존 이미지 파일, 사용자 저장 템플릿과 마이그레이션은 변경하지 않았다. 등록 후 총 17개(배경 2개, 그림 15개)다.

## 검증 통과

- Windows Chrome 및 Playwright에서 `builtin_assets_browser.cjs`: 두 화면 모두 17개 자산 선택·저장, 새 배너 6종의 실제 PNG 크기와 등록 크기 일치, 바깥 투명도 0 및 글쓰기 영역 불투명도 255, 배경 교체, PPTX 왕복, 저장 템플릿 불변성 확인.
- `image_library_browser.cjs`: 두 화면의 그림 선택·미리보기·위치/크기·저장/재열기·PPTX 왕복, 다른 자막과 원고 연결 보존, 방송용 PPT 새로고침 복원, Make 마스터 목록과 저장 확인.
- `image_library.cjs`: 분류·중복 제거·백업 제외·원본 보존 확인.
- 관련 JavaScript 문법 검사 및 `git diff --check` 통과.
- 배포 전 원본 PNG와 저장소에 추가한 PNG의 SHA-256 일치 및 기존 카탈로그 항목 보존 확인.

## 범위

이미지 카탈로그와 자산만 추가했다. 실제 마이크·물리 외부 모니터 송출·클라우드 동기화는 이번 변경 범위 밖이며 별도로 검증하지 않았다. GitHub Pages 배포 상태는 커밋 반영 후 별도 확인한다.
