# 프롬프터 공개 코드 비교 · 2026-10-17

분석 대상은 로그인 없이 받은 브라우저 배포 코드와 공개 화면이다. 서버 구현과 실제 이용 중 활성화되는 모든 경로는 확인할 수 없다. 제3자 코드를 복사하지 않고 아래 원리를 현재 프로젝트에 맞게 구현했다.

| 대상 | 공개 코드에서 확인한 점 | prom에 적용한 판단 |

| FlowPrompter | 프레임 시간 기반 스크롤, 수동 이동·일시정지 상태 구분, 초안 로컬 저장 | 읽는 위치·크기·줄간격을 재생 화면에서 조절하고 현재 줄을 유지 |
| FlowPrompter 음성 경로 | Deepgram WebSocket 연결, interim/final 단어 전달, 지연 계측과 재연결·대체 공급자 경로. 후보 구간을 판정하는 AI 조언 요청 코드도 포함 | 외부 유료 음성·AI 서비스를 추가하지 않고 현재 브라우저 인식 결과의 처리와 복구부터 개선. 해당 코드가 모든 이용자에게 활성화된다는 뜻은 아님 |

## 구현 경계

- `lineSpeech`: 현재 줄·다음 줄 범위에서 정규화한 한글·숫자·영문을 비교한다. 한 단어만으로 먼 위치를 확정하지 않는다. 다음 줄 이동은 더 긴 근거를 요구한다.
- `confirmedSpeech`: 현재 쪽과 다음 쪽의 제한된 범위에서 28자 이상 고유한 정확 일치 또는 40자·최대 2개 편집 오류의 단일 후보로 밀린 인식을 복구한다. 모호하면 기존 확인 흐름을 유지한다.
- 한국어 띄어쓰기 변동 때문에 영문식 단어 토큰을 그대로 이식하지 않는다. 숫자·장절 실험실은 기존 원고 위치 매핑을 유지한다.
- 음성 위치 판단과 화면 이동을 분리한다. 긴 결과로 커서가 앞서도 화면 이동은 기존 줄 속도 제한을 따른다. 말하지 않아도 임의로 전진하는 추측은 추가하지 않았다.
- 줄 클릭은 음성 결과 시작 인덱스를 새로 잡는다. 클릭 전 누적 음성으로 기존 위치에 복귀하지 않는다. OBS 영상 표식과 수동 위치 이동은 기존 계약을 유지한다.
- 실제 마이크 환경은 별도 확인이 필요하다. 자동 검증은 인식 텍스트 입력, 화면 배치, 기존 영상 전환 회귀 테스트를 대상으로 한다.
