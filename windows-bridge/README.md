# OBS 전체화면 전환 · 1.3.1 (수정 검증판)

Windows 10/11에서 `PromWindowBridge.exe`를 더블클릭합니다. PowerShell 실행이나 설치 과정은 필요 없습니다. 기존 PowerShell 보조 프로그램을 켜 두었다면 먼저 종료합니다.

현재 사이트의 [윈도우 프로그램 1.3 다운로드](https://patrickdfg.github.io/prom/downloads/OBSFullscreenBridge-1.3.0.exe)는 **기존 1.3.0** 파일입니다. 이 문서의 1.3.1 수정본은 Windows 자동 빌드와 실사용 검증을 마친 뒤 배포합니다. 브랜치 PR의 GitHub Actions 아티팩트 `OBSFullscreenBridge-1.3.1-test`는 수동 확인용 파일입니다.

OBS의 **전체화면 프로젝터**(프로그램 또는 미리보기)를 하나 열고 슬라이드 창과 같은 모니터에 배치합니다. Google 슬라이드 등 다른 발표 창의 제목은 구분할 필요가 없습니다. 프로그램은 OBS 프로세스의 프로젝터 제목과 모니터 전체 크기를 확인하여 대상 창을 선택합니다. OBS 편집창과 작은 프로젝터 창은 제외하고, 전체화면 프로젝터가 여러 개이면 임의로 선택하지 않습니다.

- **Ctrl+Alt+F8 (새 기본 단축키)**: OBS 전체화면이 보이면 뒤로 보내 PPT를 표시하고, 가려져 있으면 앞으로 가져옵니다. 키를 길게 눌러도 한 번만 전환됩니다. **기존에 직접 지정한 단축키 설정은 유지**합니다.
- **토글 단축키 사용**: 체크를 끄면 지정된 키가 원래 동작으로 돌아갑니다. 켜져 있는 동안 지정한 키는 시스템 전체에서 화면 전환 전용입니다. `PgDn`을 지정했다면 PowerPoint의 다음 슬라이드와 충돌하므로 다른 키로 변경하세요.
- **전체화면 앞으로 / 전체화면 뒤로**: 직접 전환하는 시험 버튼입니다.
- **토글키 설정…**: 버튼을 누른 뒤 원하는 키(예: F8, Ctrl+F8)를 누르고 **저장**합니다. 기본 단축키 대신 새 키로 OBS 전체화면을 앞/뒤 토글합니다. 기존 키의 등록은 해제되며 토글키는 하나만 사용합니다. **설정 해제**로 지울 수 있습니다. 설정은 이 PC에 저장되어 다음 실행에도 유지됩니다. 다른 프로그램과 충돌하면 이전 토글키를 유지하며 알립니다.
- 상태 창의 X나 **트레이로 숨기기**는 프로그램을 종료하지 않습니다. X로 상태 창을 닫으면 OBS 프로젝터를 뒤로 보내고 트레이로 숨깁니다. 시계 옆 트레이 아이콘을 두 번 클릭하면 상태 창이 열립니다. **프로그램 종료**를 누르면 OBS 프로젝터를 뒤로 보내고 단축키와 연결을 해제합니다.

기존 원고 표식 `(영상1 시작)` / `(영상1 끝)` 및 `(영상)` / `(영상끝)`도 그대로 동작합니다. 시작은 OBS 전체화면을 앞으로, 끝은 뒤로 보냅니다. 프로그램은 전체화면 프로젝터 창만 조작하며 위치·크기를 유지합니다. OBS를 앞으로 올려도 Windows의 영구적인 `항상 위` 속성을 남기지 않습니다. OBS가 실제 키보드 포커스를 가지고 있고 앞서 PowerPoint가 활성화되어 있었다면, 뒤로 전환하면서 PowerPoint 포커스 복원을 시도합니다. Windows의 포커스 변경 제한으로 실제 복원이 거절될 수 있으므로 방송 전 PPT 이전·다음 키를 확인하세요. 화면 중심이 다른 창에 가려져 있는지를 확인해 수동 창 순서 변경 후에도 토글할 수 있습니다.

웹 연결은 `127.0.0.1:17986`에서만 받으며, 창 전환 요청은 기존 프롬프터 사이트 Origin과 경로를 검사합니다. `/health`는 준비 상태와 OBS 전체화면 표시 상태를 반환합니다. 단축키는 웹 연결 없이도 동작합니다. 실행 중인 프로그램을 다시 열면 기존 상태 창을 표시합니다. 자동 시작은 등록하지 않습니다.

## 빌드 및 검사

Windows .NET Framework 4.x 기본 컴파일러로 빌드합니다. 추가 패키지나 .NET SDK가 필요 없습니다.

```powershell
.\windows-bridge\build.ps1
```

`tests/windows_bridge_tests.cs`를 빌드한 EXE를 참조하여 콘솔 프로그램으로 컴파일한 뒤 실행하면, 모의 창으로 토글/표식 전환/실패 처리와 실제 로컬 HTTP 요청의 Origin 검사/응답을 검증합니다.
