여러 파일은 위에 표시된 순서대로 이어지고, 붙여넣은 원고는 그 뒤에 추가됩니다.

만들기 설정

내 구글 드라이브

드라이브에 올리고 가져오는 것은 모두 버튼을 눌렀을 때만 합니다. ② 템플릿 만들기 목록의 「드라이브에 저장」으로 하나씩, 여기의 「드라이브에 모두 저장」으로 한꺼번에 올립니다.

슬라이드를 눌러 고르고, 두 번 누르거나 「편집」을 누르면 편집 창이 열립니다. 고친 내용은 PPTX에 그대로 들어갑니다.

원고 + 완성 PPT로 템플릿 만들기

같은 내용의 원고와, 그 원고로 만든 완성 PPT를 넣으면 글꼴·크기·위치·배경을 배워 템플릿으로 저장합니다.

저장된 템플릿

템플릿은 이 컴퓨터의 크롬에 저장되며 방송용 PPT 앱과 함께 씁니다.

기본 디자인으로 새 템플릿

완성 PPT 없이 기본 디자인에서 시작해 ③ 마스터 편집에서 직접 고칩니다.

템플릿 복제

지침 수정

이 템플릿에 붙어 있는 만들기 지침 글입니다(색 규칙·글꼴·줄간격·누적 공개 같은 약속을 적어 둔 메모). 템플릿과 함께 저장되고 「파일로 받기」·드라이브 저장에도 들어갑니다. 슬라이드의 모양 자체는 ③ 마스터 편집에서 고칩니다.

사이트 기본 템플릿입니다. 고치면 이 기기에서는 고친 내용이 유지되고, 사이트의 기본 템플릿이 새로 바뀌어도 덮어쓰지 않습니다.

자막 편집

빨강은 <r>…</r>, 파랑은 <b>…</b>로 표시됩니다.

글꼴 이름을 직접 입력할 수도 있습니다. 마루 부리는 웹에서 제공되며, 다른 글꼴은 이 PC에 설치되어 있어야 표시됩니다.

선택한 글상자 전체에 적용됩니다. 값을 바꾸면 오른쪽 미리보기에 반영됩니다.

글상자 위치·크기 (%)

왼쪽·위쪽은 -100~200%, 너비·높이는 1~300%까지 조절할 수 있습니다. 화면 밖 부분은 송출할 때 잘립니다.

원고 연결 · 자동 송출

마이크로 시작~끝 줄을 읽을 때 이 자막이 자동으로 표시됩니다. 두 칸을 비우면 직접 눌러 송출합니다.
