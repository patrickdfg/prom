OBS 풀스크린 전환 안내

어떤 용도인가요?
같은 모니터에 띄운 OBS 전체화면 프로젝터와 슬라이드쇼를 번갈아 보여 주는 Windows용 보조 프로그램입니다. OBS 전체화면을 앞으로 가져오거나 뒤로 보내며, 조작창은 그대로 유지합니다.

연결 안 함 · 영상이 없는 날은 연결하지 않아도 됩니다.

프로그램을 실행한 뒤 보조 프로그램 연결을 누르세요. 연결하지 않으면 응답 확인이나 자동 재시도를 하지 않습니다. 새로고침 후에는 다시 연결하세요.

  1. 아래 버튼으로 프로그램을 내려받고 OBSFullscreenBridge.exe를 실행하세요. 설치나 PowerShell 실행은 필요 없습니다. 기존 PowerShell 보조 프로그램이 실행 중이면 먼저 종료하세요.
  2. OBS에서 전체화면 프로젝터(프로그램 또는 미리보기)를 하나 열고, 슬라이드쇼와 같은 모니터에 띄우세요. OBS 편집창이나 작은 프로젝터 창은 전환 대상이 아닙니다.
  3. PgDn을 누를 때마다 OBS 전체화면이 앞/뒤로 전환됩니다. 뒤로 보내면 그 아래의 슬라이드쇼가 보입니다. 보조 프로그램의 토글키 설정…에서 다른 키로 바꿀 수 있습니다.
  4. 원고에 (영상1 시작)을 넣으면 OBS 전체화면을 앞으로, (영상1 끝)을 넣으면 뒤로 보냅니다. 영상 이름은 바꿀 수 있으며, 기존 (영상)·(영상끝)도 사용할 수 있습니다.

사용 중에는 보조 프로그램을 켜 두세요. 창의 X는 트레이로 숨기기이며, 다시 보려면 시계 옆 아이콘을 두 번 클릭하세요. 지정한 토글키는 화면 전환에 사용되므로 원고 넘기기는 다른 키나 버튼을 사용하세요.
