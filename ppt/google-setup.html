구글 연결은 운영자가 한 번만 설정합니다

일반 사용자는 ‘구글 로그인’ → 자기 계정 선택 → 파일 접근 허용만 하면 됩니다. 모든 사람이 운영자 계정을 사용하는 방식이 아닙니다.

  1. Google Cloud Console에서 운영자 계정으로 로그인하고 프로젝트를 만듭니다. 이름 예: PROM PPT.
  2. Google Drive API에서 해당 프로젝트를 선택하고 사용을 누릅니다.
  3. Google Auth Platform에서 앱 이름, 사용자 지원 이메일, 개발자 연락처를 설정합니다. 대상은 외부로 선택합니다. 홈페이지는 https://patrickdfg.github.io/prom/ppt/, 개인정보 안내는 https://patrickdfg.github.io/prom/ppt/privacy.html입니다. Google이 요청하는 도메인 확인·앱 게시 조건도 완료하세요.
  4. 데이터 액세스에 https://www.googleapis.com/auth/drive.file 범위를 추가합니다. 드라이브 전체 접근 범위는 추가하지 않습니다.
  5. 클라이언트 → 클라이언트 만들기 → 웹 애플리케이션을 선택합니다. 승인된 JavaScript 원본에 https://patrickdfg.github.io를 넣습니다. 경로 /prom/ppt/는 넣지 않습니다. 이 앱의 팝업 방식에는 리디렉션 URI가 필요하지 않습니다.
  6. 생성된 클라이언트 ID를 복사해서 제작 대화에 보내 주세요. 끝이 .apps.googleusercontent.com인 값입니다. 클라이언트 보안 비밀번호는 보내거나 저장소에 넣지 마세요. 운영자가 직접 적용하려면 저장소의 ppt/drive-config.js에 공개 클라이언트 ID를 넣고 배포합니다.
  7. 테스트 상태에서는 테스트 사용자에 사용할 계정들을 등록합니다. 다른 사람도 자유롭게 쓰게 하려면 대상에서 앱을 프로덕션으로 게시하고 Google이 표시하는 필요한 확인 절차를 완료합니다.

실제 계정으로 로그인 → 예시 저장 → 로그아웃 → 다른 계정에서 ‘내 자료’가 분리되는지 확인한 후 공개하세요. 회사·학교 계정은 조직 관리자의 앱 접근 제한이 있을 수 있습니다.
