# 설교 자막 송출

`https://patrickdfg.github.io/prom/ppt/`

기존 PROM과 분리된 조작창 및 자막 송출창입니다. 원고 전문을 따라가다가 연결된 PPTX 자막 구간에서만 해당 슬라이드를 표시하고, 나머지 구간은 `#00ff00` 녹색으로 표시합니다.

## 사용 순서

1. HWP/HWPX/DOCX/TXT 원고와 PPTX 자막을 불러옵니다.
2. 오른쪽 연결 결과를 확인합니다. 정확히 일치하는 자막은 자동 연결합니다. 반복 문장·유사 문장은 ‘확인 필요’, 찾지 못한 자막은 ‘미연결’로 두며 자동 송출하지 않습니다.
3. 확인이 필요한 자막을 선택하고 왼쪽 원고의 시작·끝 줄을 지정한 뒤 ‘연결 저장’을 누릅니다. 한 줄 안에서 일부 문장만 연결한 자동 구간도 원래 문자 위치를 유지합니다. 수동 연결은 지정한 줄 전체를 사용하므로 겹치는 구간은 허용하지 않습니다.
4. ‘송출창 열기’로 별도 창을 열고 원하는 모니터로 옮깁니다. 화면을 클릭해 전체화면으로 전환합니다.
5. 조작창에서 ‘자동 송출’을 켜고 마이크를 시작합니다. 원고를 클릭하면 추적 위치를 다시 지정할 수 있습니다.

자동 송출 중 연결된 자막 카드를 누르면 원고 위치도 해당 구간으로 이동하며 자동 추적을 유지합니다. 미연결 카드를 누르거나 녹색 화면(G), 선택 자막 송출, 이전·다음 자막을 사용하면 수동 유지 상태로 전환합니다. 자동 송출을 다시 켜면 현재 원고 위치로 돌아갑니다. 음성 추적 위치가 자막 구간 끝에 도달하면 즉시 녹색으로 전환합니다. 음성 일치가 8초간 없거나 송출창이 조작창과 8초간 연결되지 않으면 녹색으로 전환합니다.

작업은 IndexedDB에 자동 저장되며 JSON 작업 파일로 내보내기/가져오기를 지원합니다. 불러온 원고, PPT 및 작업 파일을 서버에 업로드하지 않습니다. 브라우저 음성 인식은 브라우저 제공자의 온라인 서비스를 사용할 수 있습니다.

## 지원 범위

PPTX 실제 슬라이드 순서, 마스터/레이아웃 배경, 정적인 그림, 텍스트 자리표시자 위치, 글꼴·색상·굵기·줄바꿈을 읽습니다. PowerPoint 프로그램을 실행하는 방식이 아닙니다. 설치되지 않은 글꼴은 대체되며 차트, 표, 애니메이션, 그룹 변형, 일부 이미지 효과는 정확히 재현되지 않을 수 있습니다. 가져오기 경고와 송출 미리보기를 확인하세요. 구형 `.ppt`는 `.pptx`로 변환해야 합니다.

음성 인식은 한국어 브라우저 인식 결과와 원고의 문자 구간을 비교하며, 현재 위치 앞뒤 제한 범위에서만 이동합니다. 원고 외 발화는 위치를 유지합니다. 마이크 권한 거부·장치 오류는 재시도를 중단하고, 일시적 종료는 지연을 두고 재시작합니다. 실제 음향·발음에 따른 현장 리허설이 필요합니다.

## 개발 및 검증

- 기존 PROM 파일은 변경하지 않습니다.
- `vendor.js`: 기존 PROM에 포함된 JSZip 3.10.1(MIT) 및 SheetJS CFB(Apache-2.0) 복사본. 원본 라이선스 안내를 유지합니다.
- `hwp-reader.js`: 기존 PROM HWP 5 파서를 분리해 문단을 원고 줄로 사용합니다.
- `core.js`: 자막 연결과 음성 위치 매칭. `node ppt/tests/core.cjs`로 단위 검증합니다.
- `importers.js`: HWP 계열 및 OOXML 읽기.
- `render.js`: 조작 미리보기와 별도 송출창이 공유하는 슬라이드 표시.
- 실제 첨부 HWP/PPTX(원고 311줄, 자막 40장)로 38장 정확 연결, 1장 확인 필요, 1장 미연결을 확인했습니다. 원본 파일이나 내용은 저장소에 포함하지 않습니다.
- 실제 브라우저에서 파일 업로드, 두 창 송출, 자막/녹색 전환, 모의 음성 이벤트, 수동 제어, IndexedDB 복원을 검증했습니다. 실제 마이크 음향 인식은 현장에서 확인해야 합니다.

## 화면 구성

- 원고의 연결된 자막 부분은 앞뒤 내용과 별도 줄로 나누고 노란색으로 구분합니다. 원고 연결은 문자 위치를 유지하며 화면에 표시된 줄 번호로 수동 연결합니다.
- 오른쪽은 PROM 조작창처럼 여러 장 보기가 기본입니다. 카드 크기(60~180%)에 따라 열 수가 바뀌며, 현재 장 찾기와 한 장 보기를 지원합니다. 송출 중인 카드는 테두리와 배지로 강조합니다.
- 가운데 경계를 드래그하거나 방향키로 조절할 수 있습니다. 기본 원고 폭은 50%이며 조절한 폭은 이 기기에 저장합니다.
- 송출은 1920×1080(16:9) 화면을 기준으로 사용합니다. 다른 비율에서는 화면 전체에 맞춰 가로·세로를 각각 조절하여 추가 여백이 생기지 않습니다.

## PPT 텍스트 서식

마루 부리 보통·굵은 웹폰트는 NAVER 공식 배포 주소에서 불러옵니다(`fonts/LICENSE.txt`). 원본의 한글 글꼴 이름을 해당 실제 글꼴 파일로 연결하며 브라우저 가상 굵기를 사용하지 않습니다. 슬라이드·레이아웃·마스터 서식을 속성별로 상속하고, 글자 크기, 자간, 문단 앞뒤 간격, 줄간격, 여백, 들여쓰기, 세로 정렬 및 저장된 자동 축소 비율을 반영합니다. 공백·탭·강제 줄바꿈을 보존합니다.

기존에 저장한 작업은 가져오기 단계에서 누락된 서식을 복원할 수 없으므로 PPTX를 한 번 다시 불러와야 합니다. 웹폰트를 처음 불러올 때 인터넷 연결이 필요합니다. 다른 글꼴은 해당 기기에 설치되어 있어야 합니다. HTML과 PowerPoint의 글자 배치 엔진이 달라 모든 PPT의 픽셀 단위 동일성을 보장하지는 않습니다.

회귀 검증: 로컬 HTTP 서버에서 `ppt/tests/fidelity.html`을 열면 서식 상속, 빈 기본 서식, 명시적 굵기 해제, 좌표, 자동 축소, 공백, 줄바꿈, 웹폰트 로드를 확인합니다. 실제 40장 원본으로 글꼴 로드와 텍스트 상자 잘림 여부를 추가 확인했습니다.

## 송출 영역 보호

전체 화면용 배경 그림과 PPT 배경 이미지는 화면 가장자리까지 채웁니다. 글자 상자는 원래 위치를 유지하고, 웹폰트 로드 후 실제 줄 크기를 다시 측정하여 넘치는 경우에만 내용 전체를 비례 축소합니다. 이미 들어가는 자막의 글자 크기는 유지합니다.

조작 버튼과 설교 전문은 왼쪽, 자막 여러 장 보기는 오른쪽 맨 위부터 표시합니다. 크기 슬라이더·숫자 입력 및 ‘3줄 맞춤’으로 조절할 수 있습니다. 100%에서는 화면 높이에 최소 세 줄의 카드가 들어가는 크기를 계산합니다.
