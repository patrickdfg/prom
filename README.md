## OBS 창 전환

최신 윈도우 프로그램은 [OBS 전체화면 전환](windows-bridge/README.md)을 사용합니다. PgDn으로 OBS **전체화면 프로젝터**만 앞/뒤로 전환하며 OBS 편집창은 제외합니다. 원고의 영상 시작은 전체화면을 앞으로, 영상 끝은 뒤로 보냅니다. 아래 PowerShell 방식은 이전 슬라이드쇼 제어 방식입니다.

보조 프로그램을 실행한 날에만 **더보기 → OBS풀스크린설명 → 보조 프로그램 연결**을 누릅니다. 새로고침하면 연결 사용은 해제됩니다. 연결하지 않았거나 원고에 영상 명령이 없으면 응답 확인·창 전환·재시도 요청을 보내지 않습니다. 연결 중 프로그램을 종료하면 자동 재연결 없이 연결 사용을 해제합니다.

영상 명령은 쪽을 여는 시점이 아니라 **음성으로 읽은 위치**에 따라 실행합니다. `(영상1 시작)` 앞의 문장을 다 읽으면 OBS 전체화면을 앞으로, 영상의 마지막 대사를 다 읽어 `(영상1 끝)`에 도달하면 뒤로 보냅니다. 영상 자막·대사는 원고에 포함하고 마이크로 계속 추적합니다. 영상 표식은 음성 대조와 읽어주기에서 제외하며, 같은 쪽에 여러 표식이 있어도 순서대로 처리합니다. 표식이 화면 줄바꿈으로 나뉘어도 인식합니다. 일반 괄호 문장은 그대로 읽을 본문으로 유지합니다.

`obs-window-bridge.ps1`을 내려받아 `powershell -NoProfile -ExecutionPolicy Bypass -File .\obs-window-bridge.ps1`로 실행하고 계속 켜 둡니다. 업데이트한 뒤에는 기존 보조 프로그램을 종료하고 다시 실행해야 합니다. Windows PowerShell 5.1에서도 인코딩 오류가 없도록 실행 파일은 ASCII로 유지합니다.

OBS 전체화면 프로젝터와 프롬프터의 **슬라이드쇼** 창을 열고, 두 발표 창을 같은 외부 모니터에 배치합니다. `(영상 찬양 시작)` / `(영상1 시작)`은 슬라이드쇼를 맨 뒤로 보내 OBS가 보이게 하고, `(영상 특별영상 끝)` / `(영상3 끝)`은 슬라이드쇼를 맨 앞으로 올립니다. 기존 `(영상)` / `(영상끝)`도 지원합니다. 조작창의 위치·크기와 키보드 초점은 유지합니다.

OBS 창을 검색하거나 조작하지 않고 Chrome/Edge의 제목에 `슬라이드쇼`가 있는 창만 조작합니다. 앞에 표시할 때는 최상위 상태로 두고, 뒤로 보낼 때 최상위 상태도 해제합니다. `http://127.0.0.1:17986/health`에서 보조 프로그램과 슬라이드쇼 창의 준비 여부를 확인할 수 있습니다. 전환 실패는 화면에 안내하며 성공한 요청만 중복 방지에 기록합니다. 실패 후에는 3초 뒤 다음 화면 갱신에서 재시도합니다. 웹 업데이트 후에는 프롬프터를 새로고침하세요.

- 하단 조작부에 마이크·읽어주기, 쪽 이동·검색, 속도 표시·읽은 줄 흐리게, 발표 메모·편집·저장·열기를 둡니다. 마이크 설정·넘김·강조 등은 **더보기**에 있습니다.
- 키보드 방향키, Page Up / Page Down (발표 리모컨 포함), Home을 지원합니다. M 마이크, E 편집, F 전체화면입니다.

## 추가 도구

- **검색**: 전체 원고에서 찾거나 쪽별 첫 줄을 보고 이동합니다. Ctrl/Cmd+F로 열 수 있습니다.
- **발표 메모**: 하단 발표 메모를 누르면 원고와 별개인 빨간 텍스트 레이어가 생기며 바로 입력할 수 있습니다. 메모 위의 이동 손잡이를 끌어 원고 영역 어디든 옮기고, 상단 도구에서 글자 크기를 12~96px로 조절합니다. 이동 손잡이에 초점을 두고 방향키(Shift: 10px)로도 옮깁니다. 완료 또는 Esc로 저장하고, 메모를 다시 누르면 수정합니다. 여러 메모를 만들 수 있으며 선택한 메모만 삭제할 수 있습니다. 메모 내용·상대 위치·글자 크기는 쪽마다 저장합니다. 마이크·읽어주기 중에는 숨기며 음성 정렬과 슬라이드쇼에도 포함하지 않습니다. 기존 쪽 메모·줄별 메모도 가져옵니다.
- **슬라이드쇼**: 새 창을 외부 모니터로 옮기면 조작부와 메모 없이 현재 원고·강조·읽기 위치가 표시됩니다. 같은 브라우저의 창끼리 연결되며 다른 기기 연결은 지원하지 않습니다. 팝업 허용이 필요할 수 있습니다.

## 자동 저장

최근 원고 1개, 읽던 쪽, 메모를 이 브라우저의 `promWorkspaceV1`에 보관합니다. 서버에 올리지 않습니다. 새로고침 후 **이어서 시작**을 누르면 복구되며 마이크는 꺼진 상태로 해당 쪽의 맨 위부터 시작합니다. 기기·브라우저 간 공유는 **저장**으로 JSON을 내려받아 사용합니다. 메모도 JSON에 포함되며 기존 JSON도 열립니다.

브라우저 저장이 차단되거나 공간이 부족하면 안내가 표시됩니다. 공용 기기에서는 사용 후 사이트 데이터를 지워 주세요.

### 모바일 마이크 반복음

안드로이드 음성인식 시작·종료음은 웹에서 음소거할 수 없습니다. 모바일에서는 인식 종료 후 입력 크기를 지켜보다가 지속된 소리가 있을 때만 재연결합니다. 디지털 무음(0), 입력 권한 실패를 이유로 주기적으로 다시 켜던 경로를 제거했습니다. 처음 0.5초 종료음과 1.5초 이내의 재연결을 걸러 내고, 인식 결과 없는 연결이 세 번 이어지면 멈춥니다. 입력 감지가 불가능하거나 네트워크·마이크 오류가 나도 반복 재시도하지 않고 안내합니다.

다시 말하기 시작한 첫 부분은 재연결 중 놓칠 수 있으며, 실제 연결할 때의 기기 알림음은 남을 수 있습니다. 조용한 상태의 대기·말소리 재개·오류·늦은 권한 응답·정지 시 예약 취소는 `node tests/mobile_wait.cjs`로 확인합니다. 실제 안드로이드 단말의 음량·알림음과 인식 품질은 별도 실기기 확인이 필요합니다.

### 실험실 · 다음 장 첫 줄 (2026-10-15)
하단 조작부의 **실험실 · 다음 장 첫 줄**을 체크하면 본문 줄 간격을 좁히고, 화면 맨 아래에 다음 장의 첫 본문 줄을 하늘색(밝은 배경은 청록색)으로 표시합니다. 선택은 이 기기에 저장하며 기본은 꺼짐입니다. 마지막 장과 본문 편집 중에는 표시하지 않습니다. 슬라이드쇼에도 함께 표시합니다.

현재 장에서 음성 추적이 멈췄을 때 하단 문장을 계속 읽을 수 있습니다. 인식된 말 끝부분 8자 이상이 다음 장 첫 줄과 정확히 맞고 현재 장에 같은 구절이 없으면 다음 장으로 이동합니다. 짧거나 반복되는 문구는 기존 추적 기준을 사용합니다. 미리보기는 원고·저장 파일·읽어주기에 중복 추가되지 않습니다. 실제 마이크의 인식 오류까지 보장하는 기능은 아닙니다.

### 여러 장 보기 (2026-10-15)
하단 **한 장 / 여러 장** 버튼으로 조작 화면을 전환합니다. 여러 장 보기에서는 원고를 작은 카드로 나란히 표시하며 상단 크기 슬라이더(60~180%)로 크기를 조절합니다. 카드를 클릭하면 해당 장으로 이동하고, 더블클릭하면 한 장 보기로 돌아갑니다. 현재 장은 파란 테두리로 구분하며 음성 자동 넘김도 따라갑니다. **현재 장 찾기**로 읽는 장을 다시 찾을 수 있습니다. 마이크 중에도 여러 장 보기의 조작부는 표시합니다.

슬라이드쇼에는 현재 장 한 장만 전송합니다. 목록을 스크롤하거나 카드 크기를 바꾸는 것만으로는 발표 페이지가 바뀌지 않습니다. 본문·메모 편집을 누르면 한 장 보기로 돌아갑니다. 카드 크기는 기기에 저장하며 원고 내용·순서는 바꾸지 않습니다.

2026-10-15 조작 버튼 정리: **슬라이드쇼**과 **⌂ 홈**을 조작 화면 윗줄에 배치했습니다. 홈은 기존 다른 원고 버튼과 같은 동작입니다. 슬라이드쇼 창이 전체화면이면 전체화면 버튼을 숨기고, Esc로 빠져나오면 다시 표시합니다. 전체화면에서 마우스를 움직여도 버튼은 나타나지 않습니다.

슬라이드쇼 버튼은 새 창에서 자동 전체화면을 요청합니다. 브라우저가 새 창의 자동 전체화면을 차단하면 슬라이드 영역을 한 번 클릭해 시작할 수 있습니다. 이미 열린 창은 다시 불러오지 않고 해당 창을 앞으로 가져와 전체화면을 요청하므로 발표 연결을 유지합니다.
