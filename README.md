# 음성 설교 프롬프터

배포: https://patrickdfg.github.io/prom/

이전 화면: https://patrickdfg.github.io/prom/classic.html (업그레이드 전 `e4e4164`의 원본 화면)

## 준비와 진행

- 파일 불러오기 / 글 붙여넣기 중 하나를 고르고 화면 구성과 줄 수를 정합니다.
- 마이크를 켜면 현재 쪽 맨 위부터 음성을 따라가며 원고만 전체화면으로 표시합니다. 마우스를 맨 아래 24px로 내리면 조작부가 나타나고, 벗어나면 다시 숨습니다. Esc 또는 M으로 마이크를 끄고 조작 화면으로 돌아옵니다.
- 이전·다음, 전체화면은 기본 조작부에, 나머지 기능은 **더보기**에 있습니다.
- 키보드 방향키, Page Up / Page Down (발표 리모컨 포함), Home을 지원합니다. M 마이크, E 편집, F 전체화면입니다.

## 추가 도구

- **검색 · 쪽 목록**: 전체 원고에서 찾거나 쪽별 첫 줄을 보고 이동합니다. Ctrl/Cmd+F로 열 수 있습니다.
- **발표 메모**: 더보기 → 발표 메모를 누르면 원고와 별개인 빨간 텍스트 레이어가 생기며 바로 입력할 수 있습니다. 메모 위의 이동 손잡이를 끌어 원고 영역 어디든 옮기고, 상단 도구에서 글자 크기를 12~96px로 조절합니다. 이동 손잡이에 초점을 두고 방향키(Shift: 10px)로도 옮깁니다. 완료 또는 Esc로 저장하고, 메모를 다시 누르면 수정합니다. 여러 메모를 만들 수 있으며 선택한 메모만 삭제할 수 있습니다. 메모 내용·상대 위치·글자 크기는 쪽마다 저장합니다. 마이크·읽어주기 중에는 숨기며 음성 정렬과 별도 원고 화면에도 포함하지 않습니다. 기존 쪽 메모·줄별 메모도 가져옵니다.
- **별도 원고 화면**: 새 창을 외부 모니터로 옮기면 조작부와 메모 없이 현재 원고·강조·읽기 위치가 표시됩니다. 같은 브라우저의 창끼리 연결되며 다른 기기 연결은 지원하지 않습니다. 팝업 허용이 필요할 수 있습니다.

## 자동 저장

최근 원고 1개, 읽던 쪽, 메모를 이 브라우저의 `promWorkspaceV1`에 보관합니다. 서버에 올리지 않습니다. 새로고침 후 **이어서 시작**을 누르면 복구되며 마이크는 꺼진 상태로 해당 쪽의 맨 위부터 시작합니다. 기기·브라우저 간 공유는 **저장**으로 JSON을 내려받아 사용합니다. 메모도 JSON에 포함되며 기존 JSON도 열립니다.

브라우저 저장이 차단되거나 공간이 부족하면 안내가 표시됩니다. 공용 기기에서는 사용 후 사이트 데이터를 지워 주세요.

## 구조와 확인

- `index.html`: 기존 문서 변환·편집·음성 정렬과 주요 화면
- `workspace.css`, `workspace.js`: 준비·탐색·메모·복구 도구
- `audience.html`, `audience.css`, `audience.js`: 별도 모니터용 원고 화면
- `read.html`: 기존 원고 읽어주기

수정 시 인라인 및 외부 JavaScript 문법 검사와 함께, 원고 시작 → 검색 이동 → 메모 저장 → 새로고침 복구 → 편집 → 외부 화면 동기화와 모바일 배치를 확인합니다. 실제 마이크 연결·음성 서버와 물리 리모컨은 해당 장비에서 별도로 확인합니다.

### 음성 추적 회귀 시험

`python tests/serve_voice_test.py` 실행 후 `http://127.0.0.1:8765/__voice_test__?version=current`의 시험 실행 버튼을 누릅니다. `version=legacy`는 업그레이드 전과 비교합니다. 모의 SpeechRecognition 이벤트로 실제 `startMic → onresult → onHeard → go/render` 흐름을 통과시키며, 실제 마이크·음성 서버는 사용하지 않습니다. 시험의 저장소도 분리하여 최근 원고에 영향을 주지 않습니다.

### 모바일 마이크 반복음

안드로이드 음성인식 시작·종료음은 웹에서 음소거할 수 없습니다. 모바일에서는 인식 종료 후 입력 크기를 지켜보다가 지속된 소리가 있을 때만 재연결합니다. 디지털 무음(0), 입력 권한 실패를 이유로 주기적으로 다시 켜던 경로를 제거했습니다. 처음 0.5초 종료음과 1.5초 이내의 재연결을 걸러 내고, 인식 결과 없는 연결이 세 번 이어지면 멈춥니다. 입력 감지가 불가능하거나 네트워크·마이크 오류가 나도 반복 재시도하지 않고 안내합니다.

다시 말하기 시작한 첫 부분은 재연결 중 놓칠 수 있으며, 실제 연결할 때의 기기 알림음은 남을 수 있습니다. 조용한 상태의 대기·말소리 재개·오류·늦은 권한 응답·정지 시 예약 취소는 `node tests/mobile_wait.cjs`로 확인합니다. 실제 안드로이드 단말의 음량·알림음과 인식 품질은 별도 실기기 확인이 필요합니다.
