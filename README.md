# 음성 설교 프롬프터

배포: https://patrickdfg.github.io/prom/

이전 화면: https://patrickdfg.github.io/prom/classic.html (업그레이드 전 `e4e4164`의 원본 화면)

## 준비와 진행

- 파일 불러오기 / 글 붙여넣기 중 하나를 고르고 화면 구성과 줄 수를 정합니다.
- 마이크를 켜면 기존 음성 추적 기능으로 원고 위치와 쪽을 따라갑니다.
- 이전·다음, 전체화면은 기본 조작부에, 나머지 기능은 **더보기**에 있습니다.
- 키보드 방향키, Page Up / Page Down (발표 리모컨 포함), Home을 지원합니다. M 마이크, E 편집, F 전체화면입니다.

## 추가 도구

- **검색 · 쪽 목록**: 전체 원고에서 찾거나 쪽별 첫 줄을 보고 이동합니다. Ctrl/Cmd+F로 열 수 있습니다.
- **여기부터 읽기**: 원고의 줄을 눌러 음성 추적 기준을 재지정합니다. Esc로 취소합니다.
- **시간**: 더보기에서 목표 분량을 정하고 시작·일시정지·초기화합니다. 종료 5분 전과 초과 시 색이 바뀝니다.
- **발표 메모**: 현재 쪽에 멈춤·강조 등의 메모를 붙입니다. 읽어주기나 별도 화면에는 들어가지 않습니다. 본문을 바꾸면 메모를 다시 확인하세요.
- **설교 전 점검**: 마이크 입력 확인, 전체화면, 리모컨 안내를 모았습니다.
- **별도 원고 화면**: 새 창을 외부 모니터로 옮기면 조작부와 메모 없이 현재 원고·강조·읽기 위치가 표시됩니다. 같은 브라우저의 창끼리 연결되며 다른 기기 연결은 지원하지 않습니다. 팝업 허용이 필요할 수 있습니다.

## 자동 저장

최근 원고 1개, 읽기 위치, 메모, 목표 시간과 경과 시간을 이 브라우저의 `promWorkspaceV1`에 보관합니다. 서버에 올리지 않습니다. 새로고침 후 **이어서 시작**을 누르면 복구되며 마이크와 타이머는 일시정지 상태로 시작합니다. 기기·브라우저 간 공유는 **저장**으로 JSON을 내려받아 사용합니다. 메모와 시간 설정도 JSON에 포함되며 기존 JSON도 열립니다.

브라우저 저장이 차단되거나 공간이 부족하면 안내가 표시됩니다. 공용 기기에서는 사용 후 사이트 데이터를 지워 주세요.

## 구조와 확인

- `index.html`: 기존 문서 변환·편집·음성 정렬과 주요 화면
- `workspace.css`, `workspace.js`: 준비·탐색·타이머·복구 도구
- `audience.html`, `audience.css`, `audience.js`: 별도 모니터용 원고 화면
- `read.html`: 기존 원고 읽어주기

수정 시 인라인 및 외부 JavaScript 문법 검사와 함께, 원고 시작 → 검색 이동 → 메모 저장 → 새로고침 복구 → 편집 → 외부 화면 동기화와 모바일 배치를 확인합니다. 실제 마이크 연결·음성 서버와 물리 리모컨은 해당 장비에서 별도로 확인합니다.

### 음성 추적 회귀 시험

`python tests/serve_voice_test.py` 실행 후 `http://127.0.0.1:8765/__voice_test__?version=current`의 시험 실행 버튼을 누릅니다. `version=legacy`는 업그레이드 전과 비교합니다. 모의 SpeechRecognition 이벤트로 실제 `startMic → onresult → onHeard → go/render` 흐름을 통과시키며, 실제 마이크·음성 서버는 사용하지 않습니다. 시험의 저장소도 분리하여 최근 원고에 영향을 주지 않습니다.

2026-10-14 음성 추적 멈춤 제보에 따라 부가 화면 호출을 오류 격리하고 화면 갱신 뒤로 미뤘습니다. 마이크 시작 시 점검용 입력·설정 창을 먼저 닫고, 인식된 말과 정렬 결과·무음 안내를 화면에 표시합니다. 이 시험은 부가 기능을 고의로 실패시켜도 쪽 넘김이 계속되는지, 점검용 입력이 해제되는지도 확인합니다. 실제 제보 환경의 원인은 모의 시험으로 확정하지 않습니다.
