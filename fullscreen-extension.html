송출창 자동 전체화면

Chrome·Edge 확장 프로그램을 한 번 설치하면, PROM·PPT 송출 팝업만 자동으로 전체화면이 됩니다. 선택한 모니터에 송출하고 기존 조작창은 유지합니다.

확장 프로그램 ZIP 다운로드
  1. ZIP 파일을 다운로드하고, 보관할 폴더에 압축을 해제하세요.
  2. Chrome 주소창에 chrome://extensions를 입력하세요. Edge는 edge://extensions입니다.
  3. 오른쪽 위 개발자 모드를 켜세요.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고, manifest.json이 들어 있는 폴더를 선택하세요.
  5. 기존 송출창을 닫고 조작창에서 Ctrl+F5 후 송출창을 다시 여세요.

다음부터 송출창에서 추가로 클릭하지 않아도 전체화면으로 전환됩니다. 일반 탭으로 직접 연 페이지에는 적용하지 않습니다. 설치 폴더는 계속 보관해 주세요.

지정된 PROM 송출 페이지에서만 작동합니다. 모든 사이트 접근·방문 기록·쿠키 권한을 요청하지 않습니다. 브라우저 창 상태 변경은 Chrome 확장 프로그램의 공식 창 관리 API를 사용합니다.
