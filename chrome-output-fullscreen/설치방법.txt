PROM 송출창 자동 전체화면 · v1.0

처음 한 번 설치 (일반 Chrome 또는 Edge)
1. ZIP 파일을 한 폴더에 압축 해제합니다.
2. Chrome 주소창에 chrome://extensions 를 입력합니다.
   Edge는 edge://extensions 를 엽니다.
3. 오른쪽 위 '개발자 모드'를 켭니다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
5. manifest.json 파일이 들어 있는 이 폴더를 선택합니다.
6. PROM/PPT 조작창을 Ctrl+F5로 새로고침하고 송출창을 다시 엽니다.

다음부터는 선택한 모니터의 송출 팝업만 자동 전체화면이 됩니다.
현재 조작창을 이동하거나 전체화면으로 바꾸지 않습니다.
기존에 열려 있던 송출창은 닫고 다시 여세요.
송출 페이지를 일반 탭으로 직접 연 경우에는 작동하지 않습니다.
개발자 모드는 확장 기능을 직접 설치하기 위한 단계이며, 사이트의 보안 설정을 변경할 필요는 없습니다.

확장 프로그램은 지정된 PROM 송출 페이지 두 종류에만 삽입됩니다.
탐색 기록, 쿠키, 모든 사이트 접근 권한을 요청하지 않습니다.
폴더를 삭제하면 확장 프로그램을 읽을 수 없으므로 보관해 주세요.
제거하려면 확장 프로그램 관리에서 이 확장의 '삭제'를 누릅니다.
